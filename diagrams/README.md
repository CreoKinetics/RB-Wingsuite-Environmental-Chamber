# Diagrams

This folder contains first-pass source diagrams for the RB Wingsuite environmental chamber build.

Current files:

| File | Purpose |
|---|---|
| `ln2_valve_train_schematic.md` | Draft P&ID-style LN2 valve train schematic with device tags and relief logic |
| `system_block_diagram.md` | Overall chamber system block diagram covering LN2, airflow, vacuum, purge, control and safety |

These are intentionally text-based Mermaid/Markdown diagrams so they can be reviewed and version-controlled quickly in GitHub. They can later be redrawn in draw.io, Visio or AutoCAD P&ID once the physical layout and exact fittings are locked.
