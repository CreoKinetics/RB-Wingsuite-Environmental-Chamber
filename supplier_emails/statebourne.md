# Statebourne Supplier Notes

## Context

Statebourne recognised the Cryostor 60 serial number, were not concerned by age, still support spares for the model, and can perform onsite full service/checks.

## Requested / to request

- Onsite service / inspection quote.
- Confirm vacuum condition / insulation performance checks.
- Check pressure-build circuit and regulator operation.
- Check liquid dispense valve, fill valve, vent valve, pressure gauge, contents gauge.
- Check/replace safety relief valve and burst disc if required.
- Correct flexible LN2 delivery hose for Cryostor 60:
  - 3701006: 1/2 in BSP x 4 ft / 1.2 m hose with strengthening sleeve.
  - 3701004: 1/2 in BSP x 5 ft / 1.5 m hose with strengthening sleeve.
  - 3701002: 1/2 in BSP x 2 m only if recommended.
- Confirm exact liquid outlet connection and hose-end fitting.
- Advise hose relief/protection; ask about 9911009 in-line relief tee.
- Ask whether phase separator is recommended for initial dispense testing only or useful for heat-exchanger coil feed.
- Quote PPE/O2 monitor options for comparison.
- Provide manual/valve-head schematic/parts diagram if available.
